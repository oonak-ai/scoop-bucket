# OonaCode Scoop bucket

Manifests only — the source repository is private; artefacts are served from `https://oonacode.oonak.ai/releases/download/`.

```powershell
scoop bucket add oonacode https://github.com/oonak-ai/scoop-bucket
scoop install oonacode
```

`oonacode.json` is regenerated by the release pipeline (`packaging/scripts/bump-manifests.mjs`) on every release; `checkver` reads `https://oonacode.oonak.ai/api/releases/latest`.
